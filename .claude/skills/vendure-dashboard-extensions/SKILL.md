## Was dieser Skill ist

Gecachte Referenz für das aktuelle, React-basierte Vendure-Dashboard. Der Nachfolger der Legacy Angular Admin UI (siehe Related skills) — für jedes neue Vendure-Projekt der richtige Einstiegspunkt für Admin-UI-Erweiterungen.

## Related skills
